# M3 — Blog, Forum, Jurnal

Branch: `m3-konten` · Acuan: [PRD 8.6–8.8, 8.13, 7](../PRD.md) · Status: **belum dimulai** (M2 selesai)

Legenda: `[x]` selesai · `[~]` sedang dikerjakan · `[ ]` belum

Lingkup (PRD 12): perubahan skema 8.6–8.8, alur review blog, moderasi forum & laporan, jurnal publik, halaman publik masing-masing, notifikasi terkait.

**Kondisi awal dari M0–M2** (yang dipakai ulang / diganti):
- `blogs.publication_status` (bool) — sementara 0 = menunggu review untuk penulis non-penerbit (B5). Diganti `status` draft/review/published.
- `threads.publication_status`, `comments` datar, `research` hanya judul/tanggal/PDF.
- Policy `BlogPolicy`/`ThreadPolicy`/`CommentPolicy` (pemilik atau moderator), permission `blog-publish` & `thread-moderate` sudah ada.
- Route publik `/berita`, `/jurnal`, `/forum` (+ `/{slug}`) saat ini empty state (`site.coming-soon`); beranda menampilkan empty state "Berita segera hadir".
- Pembersih HTML `App\Support\Html::clean`, komponen `x-site.*`, `x-dashboard.page/datatable/field`, `Upload` helper.
