# M4 — Event, Pendaftaran & Sertifikat

Branch: `m4-event` · Acuan: [PRD 8.9, 8.10, 8.11, 8.13, 7](../PRD.md) · Status: **belum dimulai** (M3 selesai)

Legenda: `[x]` selesai · `[~]` sedang dikerjakan · `[ ]` belum

Lingkup (PRD 12): skema 8.9, pendaftaran mandiri + upload bukti bayar, verifikasi, tiket QR & halaman check-in, generate sertifikat PDF via queue, verifikasi publik, rekap PPL, export.

**Kondisi awal dari M0–M3** (yang dipakai ulang / diganti):
- `events` lama: `date_start/date_end`, `event_status` (bool: 0 = terlaksana), thumbnail = nama file di `public/event/`. Modul Acara & Peserta dashboard masih view Metronic lama; peserta didaftarkan **admin**, sertifikat = upload gambar manual (dipertahankan sebagai cadangan, PRD 8.9).
- `participants`: unique `(event_id, user_id)` sudah ada (B11); `reason`/`file` wajib, `data_status` bool.
- Route publik `/pelatihan`, `/pelatihan/{slug}`, `/sertifikat/{kode}` masih empty state (`site.coming-soon`); beranda "Event Mendatang" empty state; statistik "Event Terselenggara" sementara memakai `event_status = 0`.
- Admin PC sudah punya permission `event-*`, `participant-*`, `certificate-*` tapi **belum** dibatasi ke PC-nya (event belum punya `organization_id`).
- Rute `/register` & verifikasi email dimatikan; view Breeze-nya rusak (`x-application-logo`) dan 8 test Breeze di-skip.
- `Setting.bank_account_info` (Q8) sudah ada; `Member::dues_status`, `status` (aktif/skors) sudah ada untuk menentukan biaya.
- Detail anggota & profil menampilkan "Jam PPL tersedia di M4".
- Package baru yang diizinkan PRD 5: `barryvdh/laravel-dompdf`, `simplesoftwareio/simple-qrcode`.
